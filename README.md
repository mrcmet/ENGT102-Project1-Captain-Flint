# ENGT 102 Project 1: Captain Flint Recovery Mission

This repository is the starting workspace for Project 1 in ENGT 102.

## Repository Structure

```text
ENGT102-Project1-Captain-Flint/
├── README.md
├── data/
├── documentation/
├── src/
└── testing/
```

## Folder Purpose

- `data/` — Store the project CSV dataset and other required data files.
- `documentation/` — Store project planning, requirements, technical memo, and related documentation.
- `src/` — Store Python source code for the rover mission program.
- `testing/` — Store test plans, test results, screenshots, and other testing evidence.

## Getting Started

Clone the repository to your computer:

```bash
git clone https://github.com/mrcmet/ENGT102-Project1-Captain-Flint.git
```

Open the cloned folder in Visual Studio Code or your preferred Python development environment.

## Course Expectations

Students are expected to:

- organize project files in the appropriate folders;
- commit work regularly using clear commit messages;
- test program components throughout development;
- preserve evidence of engineering decisions and testing; and
- submit the completed repository as directed by the instructor.

Additional project files and instructions will be provided separately in MyCourses.
